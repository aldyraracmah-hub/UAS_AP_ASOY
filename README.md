Program 4 : Jadi, program ini tuh project yg bikin game Minesweeper++ berbasis CLI (Console) pake bahasa C++ yg udah nerapin konsep OOP (Object-Oriented Programming) penuh dalam satu class utama (tanpa bantuan struct atau library aneh - aneh, murni cuma modal array 2D statis). Di matkul Alpro (Algoritma & Pemrograman) kan diajari cara manipulasi matriks tuh, nah di sini saya pakai 2 buah matriks karaketer (char), 1 buat nyimpen state rahasia posisinya bom (X) sama angka tetangganya, 1 lagi matriks buat rendering tampilan ke user. Pas user ngeklik kotak kosong berangka 0, programnya bakal otomatis ngebuka area sekitarnya lewat fungsi rekursif Flood Fill (mirip algoritma bucket fill di microsoft paint lah). Kemudian, penentu menang di sini bukan pas kotak amannya habis, tapi nguji ketepatan logika pas nge-Flag posisi bomnya. Terakhir, buat nyatet durasi bermain, saya manfaatin fungsi time(0) dari <ctime> biar bisa tahu selisih start dan end permainan dalam satuan detik.
