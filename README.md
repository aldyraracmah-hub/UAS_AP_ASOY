Deskripsi program

Program 1 : Program Sistem Parkir Mobil Mall Prienal merupakan aplikasi berbasis Command Line Interface (CLI) yang dibuat menggunakan bahasa pemrograman C++ untuk membantu petugas dalam mengelola parkir kendaraan secara sederhana dan efisien. Program ini memungkinkan petugas memasukkan data kendaraan yang masuk berupa plat nomor, merk, dan warna mobil, kemudian menyimpan waktu masuk secara otomatis. Sistem juga dapat menampilkan daftar kendaraan yang sedang terparkir beserta lama waktu parkirnya, menghitung biaya parkir saat kendaraan keluar berdasarkan durasi parkir, serta menghapus data kendaraan setelah pembayaran selesai. Selain itu, program membatasi kapasitas parkir hingga 20 mobil dan menyediakan menu interaktif yang memudahkan petugas dalam melakukan pencatatan kendaraan masuk, melihat data parkir, melakukan transaksi pembayaran, dan keluar dari program.

Program 2 : Game Tebak Kata berbasis terminal (CLI) dibuat menggunakan bahasa C++. Pemain harus menebak kata rahasia huruf demi huruf dengan jumlah nyawa yang ditentukan berdasarkan tingkat kesulitan, yaitu Easy, Medium, atau Hard. Kata rahasia dipilih secara acak dari kumpulan kata yang tersimpan dalam array. Selama permainan, sistem menampilkan status kata, sisa nyawa, dan daftar huruf yang salah ditebak. Setiap input pemain akan divalidasi untuk mencegah duplikasi tebakan. Permainan berakhir ketika kata berhasil ditebak atau nyawa habis. Program memanfaatkan struct, pointer, fungsi, array, perulangan, percabangan, serta fitur skor, leaderboard, dan hint.

Program 3 : Sistem Manajemen Inventaris Toko adalah program berbasis Command Line Interface yang diprogram pake bahasa C++. Fungsinya simpel yaitu ngebantu para penjual mantau barang dagangan mereka biar gak pusing. Di balik layar, tiap barang dibungkus rapi pake struct dan semua datanya ditampung di dalam vector biar bisa muat sebanyak apa pun. Fiturnya juga lengkap, Mulai dari nambahin barang baru, melihat daftar semua barang, nyari barang mana yang paling mehong, sampe ngitung total aset inventaris toko. Program ini bisa ngingetin barang apa aja yang stoknya udah tipis dan kudu direstock, plus bisa update stok sat-set pake kekuatan pointer. Program ini anti-input minus berkat validasi ketat buat harga dan stok. Sistemnya jalan pake looping menu interaktif yang bakal terus ada sampai user mutusin buat keluar di menu ke-7.

Program 4 : Jadi, program ini tuh project yg bikin game Minesweeper++ berbasis CLI (Console) pake bahasa C++ yg udah nerapin konsep OOP (Object-Oriented Programming) penuh dalam satu class utama (tanpa bantuan struct atau library aneh - aneh, murni cuma modal array 2D statis). Di matkul Alpro (Algoritma & Pemrograman) kan diajari cara manipulasi matriks tuh, nah di sini saya pakai 2 buah matriks karaketer (char), 1 buat nyimpen state rahasia posisinya bom (X) sama angka tetangganya, 1 lagi matriks buat rendering tampilan ke user. Pas user ngeklik kotak kosong berangka 0, programnya bakal otomatis ngebuka area sekitarnya lewat fungsi rekursif Flood Fill (mirip algoritma bucket fill di microsoft paint lah). Kemudian, penentu menang di sini bukan pas kotak amannya habis, tapi nguji ketepatan logika pas nge-Flag posisi bomnya. Terakhir, buat nyatet durasi bermain, saya manfaatin fungsi time(0) dari <ctime> biar bisa tahu selisih start dan end permainan dalam satuan detik.

Program 5 : Program Game Tebak Negara adalah permainan sederhana berbasis Command Line Interface (CLI) yang dibuat menggunakan bahasa C++. Dalam permainan ini, pemain harus menebak nama negara berdasarkan petunjuk berupa beberapa huruf yang ditampilkan oleh sistem. Nama negara dipilih secara acak sehingga setiap ronde bisa memberikan tantangan yang berbeda. Jika jawaban pemain benar, skor akan bertambah, sedangkan jika salah skor tetap sama atau tidak bertambah. Setelah menjawab, pemain dapat memilih untuk melanjutkan permainan atau berhenti. Program ini memanfaatkan konsep dasar C++ seperti vector, string, fungsi, percabangan, perulangan, dan random untuk membuat permainan yang interaktif dan mudah dimainkan.
